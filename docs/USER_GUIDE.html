線上付款 (綠界金流)

🔹 流程

  1. 報名表送出後，系統自動建立報名記錄並產生付款訂單
  2. 瀏覽器新分頁自動開啟 綠界 NewebPay 付款頁面

LINE Bot — LIFF 綁定與群組用法

🔹 為什麼需要綁定？

綁定 LINE 帳號後，Bot 才能識別您的身份，為您查詢個人報名記錄、使用 AI 助理功能。

🔹 綁定步驟

  1. 在「設定 / 個人設定」頁面，點擊 「綁定 LINE」 按鈕
  2. LINE 授權視窗彈出，點擊「同意」
  3. 系統自動取得 LINE User ID，完成綁定

後台管理 — 賽事與報名管理

🔹 賽事管理

左側導航 → 賽事管理

  • 建立新賽事：設定名稱、日期、地點、組別
  • 編輯賽事：修改狀態（草稿 → 發布 → 報名開放 → 進行中 → 已完成）
  • 管理組別：設定距離、報名費、名額上限
  • 自訂報名欄位：依組別設定額外欄位與條件邏輯

🔹 報名管理

左側導航 → 報名管理

  • 瀏覽所有報名記錄（姓名、組別、付款狀態、號碼布）
  • 篩選依：狀態、付款、賽事、組別
  • 手動編輯：修改號碼布、備註、緊急聯絡資訊
  • 匯出報名清單（CSV / Excel）

常見問題 (FAQ)

❓ 忘記密碼怎麼辦？

到 /forgot-password 頁面輸入註冊 Email，系統會寄送密碼重設信。

❓ 報名後沒收到確認信？

請檢查垃圾郵件匣。若仍未收到，可至後台「報名管理」查詢狀態，或聯繫管理員。

❓ LINE Bot 不回訊息？

  • 確認是否在 私訊 中（群組需 tag 機器人）
  • 確認是否已 綁定 LINE 帳號（後台 → 個人設定）
  • 確認使用正確指令格式（以 / 或 ! 開頭）

❓ 可以在群組使用 AI 助理聊天嗎？

可以，需在群組中 @raceone.ai 並輸入問題。AI 助理僅限已綁定 LINE 且經授權的使用者使用。

❓ 如何修改個人資料？

登入後台 → 右上角個人頭像 → 個人設定，可修改顯示名稱、電話、綁定 LINE。

❓ 付款失敗怎麼辦？

回到報名頁重新操作，系統會建立新的付款訂單。若持續失敗，請聯繫管理員協助。
